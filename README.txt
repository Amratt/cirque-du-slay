Cirque du Slay - v1 browser vertical slice (Phaser 3.80.1, vendored in lib/).
Run: any static server, e.g.  python3 -m http.server 8642  then open http://localhost:8642/
Debug URL flags: ?fast=1 (4s waves)  ?god=1 (no damage)
Controls: WASD / arrows to move, weapons auto-fire. Esc/P or top-right button = pause. Space = next wave in shop.
Touch: press anywhere to spawn a joystick. Settings > Motion enables tilt controls.
